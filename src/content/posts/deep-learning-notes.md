## 第 1 章 Python 入门
> 本章重点在于为后续“从零实现”奠定编程和高效计算基础。
- **核心工具库**：
    
    - **NumPy**：深度学习的核心运算库。利用其多维数组（ndarray）可以极为高效地实现向量和矩阵运算。
        
    - **Matplotlib**：用于绘制激活函数曲线、损失下降图以及可视化权重特征。
        
- **核心机制——广播（Broadcasting）**：
    
    - 在标量与多维数组、或形状不同的多维数组之间进行运算时，NumPy 会自动在内部对低维或较小的数组进行扩展，使其形状与另一个数组保持一致，从而实现逐元素运算。这是后续前向传播和激活函数支持批量输入的底层技术。

## 第 2 章 感知机 (Perceptron)
> 感知机是神经网络与深度学习的算法起源。
- **基本原理**：
    
    - 接收多个输入信号，乘以各自对应的**权重（$w$）**，再加上**偏置（$b$）**。若加权总和超过 0 则输出 1（神经元被激活），否则输出 0。
        
    - **数学表达式**：$y = \begin{cases} 0 & (b + w_1x_1 + w_2x_2 \le 0) \\ 1 & (b + w_1x_1 + w_2x_2 > 0) \end{cases}$
        
- **【重点】感知机的局限性（线性和非线性）**：
    
    - **单层感知机**的实质是利用一条**直线**切分参数空间。因此它只能表示**线性空间**。
        
    - 它可以轻易实现 与门（AND）、与非门（NAND）、或门（OR），但**无法实现异或门（XOR）**，因为异或门需要一条弯曲的非线性曲线才能将空间正确切分。
        
- **【难点】多层感知机 (MLP)**：
    
    - 解决异或门的方法是**叠加层**（组合已有的门电路）。通过将单层感知机堆叠成 2 层（第 0 层输入 $\rightarrow$ 第 1 层进行逻辑加工 $\rightarrow$ 第 2 层输出），感知机就能表示**非线性空间**，在理论上多层感知机甚至可以构建计算机。

## 第 3 章 神经网络 (Neural Network)
> 神经网络最核心的进化在于引入了平滑的非线性激活函数，并实现了矩阵打包运算。
- **从感知机到神经网络的桥梁——激活函数 (Activation Function)**：
    
    - 激活函数 $h(x)$ 负责将输入信号的加权总和转换为输出信号。
        
    - **阶跃函数（感知机使用）**：以 0 为界急剧切换输出（0 或 1），其导数在绝大多数地方都为 0，无法引导网络学习。
        
    - **Sigmoid 函数**：$h(x) = \frac{1}{1 + \exp(-x)}$。曲线平滑，连续变化。
        
    - **ReLU 函数（现代最常用）**：$h(x) = \max(0, x)$。输入大于 0 时原样输出，小于等于 0 时输出 0。
        
- **【核心重点】为什么激活函数必须是非线性的？**
    
    - 如果使用线性函数（如 $h(x) = cx$），无论你加深到多少层，多层网络总是能被一个与之等效的“无隐藏层的单层网络”（$y = a \cdot x$）所代替，从而彻底**丧失叠加层的优势**。
- **多维数组与矩阵运算**：
    
    - 神经网络中层与层之间的信号传递，在数学上可以通过矩阵乘积（`np.dot`）打包进行。利用矩阵乘积，即便输出节点有成千上万个，也只需一次运算即可完成前向计算。
- **输出层的设计**：
    
    - **回归问题**（预测连续数值，如体重）：使用**恒等函数**（直接输出）。
        
    - **分类问题**（预测离散类别，如手写数字）：使用 **Softmax 函数**：$y_k = \frac{\exp(a_k)}{\sum_{i=1}^n \exp(a_i)}$。
        
    - **【重点】Softmax 的特征**：输出在 (0, 1) 之间且所有输出**总和为 1**，因此可解释为“概率”。在实现时，为了**防止溢出**，通常需要减去输入信号中的最大值。
        
- **批处理 (Batch Processing)**：
    
    - 为了提高计算效率，通常不单张输入图像，而是将数据打包成一“批”（Batch）一同送入网络计算（如将 `(784,)` 变为 `(100, 784)`）。

## 第 4 章 神经网络的学习
> 如何让计算机自动从数据中寻找最优参数。
- **泛化能力与过拟合**：
    
    - 机器学习的目标是获得处理未见数据的“泛化能力”，必须将数据集严密划分为训练数据和测试数据。只对特定训练集过度拟合的状态称为**过拟合**。
- **损失函数 (Loss Function)**：
    
    - 用于定量评估神经网络当前性能“恶劣程度”的指标。
        
    - **均方误差 (MSE)**：常用于回归任务。
        
    - **交叉熵误差 (Cross Entropy Error)**：常用于分类任务，其值仅由正确解标签所对应的概率决定（对数衰减）。
        
    - **Mini-batch 学习**：面对海量数据时，从总体中随机抽取一小部分（如从 60000 张中抽 100 张）来计算**平均损失函数**，以近似代表全局，提升训练速度。
        
- **【核心提问】为什么不用“识别精度”作为优化的指标？**
    
    - 识别精度关于参数的变化是不连续、离散的。如果微调参数，精度可能依旧是 32%，这意味着**其导数在绝大多数地方都是 0**，导致参数无法更新。而损失函数是连续变化的，其导数不为 0。
- **梯度 (Gradient) 与梯度下降法**：
    
    - 梯度是由全部变量的偏导数汇总而成的向量。**梯度的重要性质**：它指向各点处函数值**减小（或增大）最多的方向**。
        
    - **学习率（$\eta$, 超参数）**：控制每次参数沿梯度负方向更新的步长。过大会发散，过小会导致训练停滞。
        

## 第 5 章 误差反向传播法 (Backpropagation)
利用数值微分（第 4 章）计算参数梯度非常耗时，误差反向传播法通过数学解析方式实现了梯度的高速计算。

- **计算图 (Computational Graph)**：
    
    - 将复杂的复合计算过程拆解为节点（算子）和边（信号流）。
        
    - **局部计算**：无论全局多复杂，每个节点只需要专注自己的输入和输出，并计算自己的**局部导数**。
        
    - **反向传播的精髓**：从右向左传递，**上游传过来的导数 $\times$ 当前节点的局部导数** $\rightarrow$ 传递给下游。
        
- **基本节点的反向传播规律**：
    
    - **加法节点**：将上游的导数**原封不动**地传递给下游。
        
    - **乘法节点**：将上游的导数乘以正向传播时输入信号的**翻转值**。因此乘法层反向传播需要保留正向传播时的输入。
        
- **【核心难点】矩阵层（Affine 层）与 Softmax-with-Loss 层的实现**：
    
    - **Affine 层**：正向传播进行的是仿射变换（$\boldsymbol{Y} = \boldsymbol{X}\boldsymbol{W} + \boldsymbol{b}$）。利用矩阵对应维度必须一致的原则，可以严密推出其反向传播公式：
        
        - $\frac{\partial L}{\partial \boldsymbol{X}} = \frac{\partial L}{\partial \boldsymbol{Y}} \cdot \boldsymbol{W}^T$
            
        - $\frac{\partial L}{\partial \boldsymbol{W}} = \boldsymbol{X}^T \cdot \frac{\partial L}{\partial \boldsymbol{Y}}$
            
        - 偏置的梯度 $\frac{\partial L}{\partial \boldsymbol{b}}$ 则是将批量反向传播的导数沿第 0 轴（axis=0）进行求和。
            
    - **Softmax-with-Loss 层**：如果将 Softmax 激活函数和交叉熵误差（Cross Entropy Error）合并为最后一层，其反向传播会得到一个极其漂亮的解析解：$\boldsymbol{y} - \boldsymbol{t}$（即**网络的预测概率减去教师标签**）。这也是数学上特意将这两者搭配使用的精妙之处。
        
- **梯度确认 (Gradient Check)**：
    
    - 误差反向传播法代码容易写错，工程实践中通常会将反向传播算出的梯度与实现简单但不易错的**数值微分梯度**进行对比，确认两者的差距是否微乎其微。

## 第 6 章 与学习相关的技巧
> 本章是训练深度神经网络的工程实践“百宝箱”。
- **参数更新算法（最优化的选择）**：
    
    - **SGD**：简单，但在函数等高线非均匀（如鞍点、扁平山谷）时更新路径会呈“之”字形交替，效率极低。
        
    - **Momentum**：引入物理学“动量/速度（$v$）”概念。像小球下坡，会在变化方向一致的轴上加速，在剧烈震荡的轴上相互抵消，减轻“之”字荡漾。
        
    - **AdaGrad**：为每个参数动态定制学习率。过去梯度更新越大的参数，其学习率衰减得越厉害。
        
    - **Adam**：将 Momentum（动量累积）与 AdaGrad（逐参数自适应学习率调节）融合的现代最常用最优化算法。
        
- **【重点】权重的初始值（为什么不能设为 0 或相同的值？）**：
    
    - 如果初始权重完全一样，正向传播时所有隐藏层神经元接收相同信号，反向传播时也会进行**完全相同的更新**，导致网络失去了许多不同权重的现实意义（**瓦解了权重的对称结构**）。
        
    - **Xavier 初始值**：当前层与前一层有 $n$ 个节点连接时，初始值使用标准差为 $\frac{1}{\sqrt{n}}$ 的分布。**适用于 Sigmoid / tanh 激活函数**。
        
    - **He 初始值**：标准差为 $\sqrt{\frac{2}{n}}$ 的分布。**专用于 ReLU 激活函数**，能保证深层网络中各层激活值分布具备适当的广度，有效防止梯度消失。
        
- **Batch Normalization (批归一化)**：
    
    - **核心思想**：为了防止各层激活值分布发生偏向或梯度消失，通过算法“强制性”地对每个 Mini-batch 数据在各层前向传播时进行归一化（调整为均值为 0，方差为 1 的分布）。
        
    - **巨大优势**：使学习可以快速进行（可增大学习率）、降低对权重初始值的极度依赖、在一定程度上抑制过拟合。
        
- **正则化与应对过拟合**：
    
    - **权值衰减 (Weight Decay)**：在损失函数中加上权重参数的 $L_2$ 范数惩罚项，通过抑制过大的参数来防止过拟合。
        
    - **Dropout**：针对复杂多层网络，在训练时**随机删除（将输出置为 0）隐藏层中的部分神经元**。测试时再恢复全部神经元但乘以对应删除比例。
        
    - **【深度思考】**：Dropout 的本质可以理解为在单模型内部模拟了**集成学习**（每次训练都在训练一个不同的子网络，最后测试相当于对这些子网络取平均）。
        
- **超参数的验证**：
    
    - 调整超参数（如学习率、正则化系数）时，**绝对不能使用测试数据**（否则超参数会对测试集过拟合，导致泛化评估失效）。
        
    - 正确做法是从训练集中分出一部分作为**验证数据 (Validation Data)**。最优化超参数时，通常在对数尺度上（如 $10^{-8}$ 到 $10^{-2}$ 范围内）进行**随机采样遍历**，逐步缩小好值的范围。
