这个博客就是你现在看到的这棵树屋：楼下工作坊写技术，楼上起居室过日子，树冠上是实验室，树下立着木牌和信箱。每样东西都能点，点下去镜头会推过去，打开它自己的小页面。

插画由 AI 生成，网站是我和 AI 助手一起搭的。代码在 [GitHub：Cai-7/treehouse-blog](https://github.com/Cai-7/treehouse-blog)。

## 定方向：从群岛到树屋

最早的方案是一艘小船在群岛之间航行，每座岛是一个栏目。画出来之后太像《灵魂旅人》，而且“岛”和“技术、生活”对不上。

换成树屋之后，结构一下子顺了：**楼下工作坊 = 技术，楼上起居室 = 生活**。每个栏目对应屋里的一样东西，比如黑板是技术文章，双屏书桌是技术栈，书架是书单，钢琴是练琴记录，木牌是关于我。导航变成了“在屋里走动”。

## 技术选型

- **Astro 5，纯静态输出**：文章是 Markdown，书单、歌单这些是 YAML，构建出来就是一堆 HTML，放在 Netlify 上就行。
- **没有前端框架**：树屋的交互是一个原生 JavaScript 文件，不需要 React。
- **评论用 giscus**：留言存在 GitHub Discussions 里，所有人看到的是同一份，不用自己搭后端。
- **搜索用 Pagefind**：构建时生成索引，猫头鹰面板里直接全文搜索。

## 一张画怎么变成可以点的场景

**白天和夜晚是两张画。** 两张分别生成，构图一样，但同一件物品在夜景里可能偏一两个像素，切换时会抖一下。抠图时对每件物品在 ±4 像素的范围里搜一遍：两张图各提一次边缘，找边缘重合最多的偏移，记下来再导出夜景图层。

**每个物品都从画里抠出来。** 给每个物品框一个范围，交给 OpenCV 的 GrabCut 分出前景，自动结果不理想的就直接在蒙版图上手工修。抠出来的图层精确地叠在原画上，平时看不见，鼠标移上去才浮起来放大。

**所有位置都是百分比。** 物品的坐标、星星、灯泡都按整张画（1086×1448）的百分比摆放，配合容器查询单位 `cqw`，整幅画缩放时，木牌上的字和落叶都跟着一起缩。

**镜头推近只用了一个 transform。** 点一个物品，按它的位置算出缩放倍数和平移量，对整张画做 `translate + scale`。倍数有上限，免得把画放大到糊掉。

## 每样东西打开都是它自己

面板不是统一的列表。书架打开是一排书脊，钢琴打开是一本可以弹的乐谱和一排琴键，黑板上用粉笔写文章标题，信箱里是一封封来信，木牌上刻着名字。每样东西的二级页面，上面是同样可以玩的完整版，下面是同样内容的文字清单，方便阅读，也方便被搜索引擎收录。

## 住在里面的人

树屋里住着一个小人，像桌面宠物一样在屋里走来走去：一会儿弹钢琴，一会儿坐在书桌前写代码，一会儿躺在吊床上看书。她有站着、走路、弹琴、伏案、探头张望、在书架前找书、躺吊床几种姿势。点开她正在用的东西，她会跟着那样东西一起被放大。

## 字体

拉丁字母和数字用 testType，标题用霞鹜漫黑，正文中文用悠哉。中文字体文件太大，按用到的字切成小块，按需加载。

后来发现 testType 在文章正文里不好认，“Step 1”“14 个样本”这种地方几乎读不出来，于是文章正文的英文和数字换成了系统无衬线字体，只在标题和装饰处保留 testType。

## 改版：让树屋当主角

第一版是左边一张画、右边一列目录，树屋更像一张插图。改版时把树放大居中，占满一屏；欢迎语写在左边的天空里，右边四块楼层牌各自对准一层楼；点开物品时，面板从右边滑出，树往左让开。

二级页面顶部换成一扇“看进树屋的窗”：镜头推近到那件物品上；正文写在用胶带贴住的纸上；右下角有一个迷你树屋，用闪烁的小点标出你现在在哪里。

## 走过的弯路

- **一开始装不上 npm。** 搭网站的环境连不上 npm 仓库，Astro 跑不起来。于是先写了一个 Python 脚本，按同样的数据拼出单文件 HTML 预览，网站长什么样照样能看，等能装依赖了再用 Astro 正式构建。代价是要一直维护两份首页的模板。
- **文件以为同步了，其实没有。** 有一次改好的文件没真正写进本地文件夹，改完怎么刷新都看不到变化。后来每次同步完都对一下文件的校验和。
- **公式一度不渲染。** 为了“没装插件也能跑”，配置里用了可选的动态导入，结果服务器重启后插件没加载上，所有公式又变回 `$...$` 原文。装好依赖之后改回普通的静态导入就稳定了。
- **面板只显示最新 5 篇。** 黑板面板原来只放日期最新的 5 篇，几篇日期早的新文章被挤了出去，看起来像“没更新”。现在黑板可以翻完全部文章。

## 还没做

- 绑定自己的域名，正式部署；
- 邮件订阅；
- 更多小人的姿势，比如听唱片、在黑板上写字、睡觉；
- 英文版。
